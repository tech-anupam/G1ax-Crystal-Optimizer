# G1ax Crystal Optimizer

Reduce client-side delay when placing and breaking End Crystals.

G1ax Crystal Optimizer makes Crystal PvP more responsive by reducing unnecessary client-side delays and adapting optimization to your connection.

## Features

* Faster crystal placement
* Faster crystal breaking
* Reduced visual delay
* Client-side crystal prediction
* Adaptive optimization based on latency
* Multiple optimization modes
* Client-side only
* Multiplayer compatible

## Modes

| Mode        | Description                                                                 |
| ----------- | --------------------------------------------------------------------------- |
| **Default** | Full optimization with crystal prediction and adaptive packet scheduling.   |
| **Tweak**   | Vanilla-friendly mode that only removes the client-side placement cooldown. |
| **Off**     | Restores normal vanilla behavior.                                           |

## Commands

```text
/g1axoptimizer default
/g1axoptimizer tweak
/g1axoptimizer off
```

## Requirements

* Minecraft 1.21.11+
* Fabric Loader
* Fabric API

## Installation

1. Install Fabric Loader for your Minecraft version.
2. Install Fabric API.
3. Download the matching G1ax Crystal Optimizer `.jar`.
4. Place it in your `mods` folder.
5. Launch Minecraft.
